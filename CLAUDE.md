# DOPX — правила для ИИ-ассистента

## Комментарии в коде (обязательно)

- Комментарии и docstring'и — короткие, как пометки разработчика для себя: что делает и, если неочевидно, почему.
- 1–2 строки. Длиннее — только для модульных docstring'ов management-команд (usage) и неочевидных формул.
- Запрещено: даты, «жалоба пользователя», «БАГ, КОТОРЫЙ ТУТ БЫЛ», «ИСПРАВЛЕНО/НАЙДЕНО/НОВОЕ», пересказ истории правок, ссылки на переписку, рассуждения на полстраницы.
- История изменений — в git/ADR, не в коде.
- Язык комментариев — русский.

Примеры:

```python
# Sum, а не Count — нужна сумма голосов.
# Без --apply — dry-run.
```

```django
{# Шкала 1-10 -> проценты через widthratio. #}
```

## Общение

- Отвечать по-русски.
- Не задавать лишних уточняющих вопросов — выполнять задачу целиком.

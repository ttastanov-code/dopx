# 0014 — Топ игроков команды: учитывать состав конкретного матча, не текущий клуб

Дата: 2026-09-01
Статус: Accepted

## Контекст

Виджет топ-5 игроков команды (`teams/views.py`) фильтровал агрегаты игрока
через `player__team=team` — "у кого текущая команда — эта", а затем брал
все `PlayerMatchAggregate` игрока без разбора, за какую команду был сыгран
конкретный матч.

Эффект в проде: если игрок блистал в клубе А, а потом перешёл в клуб Б —
клуб А молча терял его из своего топа (`Player.team` уже указывает на Б),
а клуб Б присваивал себе его лучший матч, сыгранный ещё за А (виджет не
проверяет матч вообще, только текущую команду игрока). Матч в выдаче
показывает только дату, без названий команд — со стороны выглядело так,
будто игрок выдал высокую оценку именно за Б.

## Решение

Правильный источник "за какую команду сыгран именно этот матч" —
`MatchLineupPlayer.lineup.team` (см. `players/views.py::PlayerDetailView`,
`career_by_season`) — не перезаписывается задним числом при трансфере, в
отличие от `Player.team`. `Exists`-подзапрос проверяет для каждой пары
(`player`, `match`) из `PlayerMatchAggregate`: был ли этот игрок в составе
именно этой команды на именно этот матч.

Отдельно: гейт `total_votes__gte=MIN_VOTES_FOR_DISPLAY` — без него игрок с
одним голосом "10/10 от друга" обходит игрока с честными 40 оценками (тот
же класс проблемы, что уже был закрыт для `matches/views.py`, здесь
оставался открытым — продуктовый аудит "доверие к рейтингу", 2026-08-21).

## Дополнение: `is_active=True` в общем рейтинге игроков исключал ушедших целиком

Найдено 2026-09-01 в `players/views.py` (общий рейтинг игроков, не
страница команды). Фильтр `is_active=True` был добавлен 2026-08-31 только
чтобы починить состав команды (`teams/views.py` — не показывать в текущем
ростере игроков, которых KFF больше не видит на странице клуба). В общем
рейтинге он же исключал любого игрока, сменившего клуб/покинувшего КПЛ в
середине сезона, целиком — вместе с его реальными оценками за уже
сыгранные матчи (`PlayerMatchAggregate` никак не завязан на `is_active`).

**Решение**: сезонный рейтинг отражает результативность за сезон, а не
текущий факт трудоустройства — игрок остаётся в рейтинге, `is_active`
используется только для бейджа "покинул клуб/КПЛ" в шаблоне
(`players/list.html`), не для исключения из выдачи.

## Последствия

- Топ игроков команды и общий рейтинг игроков теперь корректны для
  игроков, сменивших клуб в середине сезона — старые матчи засчитываются
  старому клубу, новые — новому, и игрок не пропадает из рейтинга при
  уходе из лиги.

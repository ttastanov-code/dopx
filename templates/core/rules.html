Trust Score

Trust Score — показатель надёжности ваших оценок. Рассчитывается на основе соответствия вашим оценкам и средним оценкам сообщества.

ДиапазонУровеньОписаниеВес голоса
≥ 1.8ЭкспертВысокая точность оценок+20%
1.4 - 1.79НадёжныйСтабильные оценки+10%
1.0 - 1.39СтандартБазовый уровень100%
< 1.0НовичокТребуется больше оценок-20%

Как повысить Trust Score?

  • • Оценивайте больше матчей (минимум 10 для стабильности)
  • • Смотрите матчи полностью (вес +20%)
  • • Избегайте явной предвзятости к своей команде
  • • Будьте последовательны в оценках

  • • Координация оценок в чатах
  • • Использование скриптов для автоматизации

Конфиденциальность и защита данных

Мы уважаем вашу приватность

Ваши персональные данные защищены и не передаются третьим лицам без вашего согласия.

📤 Публичные данные

  • • Имя пользователя
  • • Trust Score
  • • Количество оценок
  • • Достижения
  • • Уровень

🔒 Приватные данные

  • • Email
  • • Пароль (хэшируется)
  • • IP адрес
  • • История сессий
  • • Настройки уведомлений

📋 Сбор данных

  • • Данные оценок матчей (для расчёта рейтингов)
  • • Контекст просмотра (для учёта веса голоса)
  • • Технические данные (browser, device) для безопасности
  • • Cookie для работы сессий

🛡️ Безопасность

  • • Пароли хэшируются алгоритмом PBKDF2
  • • HTTPS шифрование всех соединений
  • • Защита от CSRF-атак
  • • Регулярное резервное копирование

📧 Коммуникация

  • • Email только для важных уведомлений
  • • Возможность отписаться от рассылок
  • • Спам не рассылается

🗑️ Удаление данных

Для удаления аккаунта и всех персональных данных напишите на support@dopx.kz Удаление выполняется в течение 30 дней.

👶 Возраст

Платформа предназначена для пользователей старше 16 лет. Регистрация лиц младше 16 лет требует согласия родителей.

📍 Юрисдикция

Платформа работает в соответствии с законодательством Республики Казахстан. Все споры решаются в суде по месту регистрации компании.

РЕДИЗАЙН (2026-08-31, третий проход — полный пересмотр страницы матча): раньше это была обычная daisyUI card, неотличимая от любой другой карточки на странице. Теперь — .md-hero: полноразмерный градиентный баннер с "ambient glow" (мягкие цветные пятна на фоне, приём трансляционной графики/ презентаций уровня Apple — см. докстринг static/css/match-detail.css), счёт — единственный настоящий фокус баннера, крупная градиентная типографика вместо серой коробки. РЕДИЗАЙН (2026-08-31, четвёртый проход — откат автоцветов клубов): фичу "фирменные цвета команд в градиенте шапки" (Team.primary_color/ secondary_color, полоска .md-hero__edge сверху) продуктово отклонили — выглядела аляповато на разных сочетаниях клубов. Вернули окраску только по статусу матча (--mh-accent, live/finished/scheduled/...). РЕДИЗАЙН (2026-08-31, пятый-седьмой проходы — тиснение гербов клубов на фоне баннера, .md-hero__emboss): перепробовали три варианта (grayscale+contrast(0) — герб исчезал в белом; CSS mask-image — невидимо из-за CORS на внешних логотипах; grayscale+multiply-блендинг — формально видно, но продуктово отклонили: "очень уродливо смотрится"). Идею с гербами на фоне шапки закрыли целиком — шапка снова чистая, только окраска по статусу матча + ambient glow (без клубной айдентики). {% endcomment %}
